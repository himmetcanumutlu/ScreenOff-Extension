# ScreenOff Extension 🌙

A lightweight extension that instantly turns your browser into a full-screen pitch-black canvas with a single click.

Turn your screen pitch-black instantly with a single click. ScreenOff is a minimalist and lightweight browser extension designed to help you rest your eyes, eliminate distractions, or save energy on OLED monitors.

## ✨ Key Features

* **One-Click Blackout:** Just click the extension icon in your toolbar to instantly open a full-screen black page.
* **Zero Distractions:** The mouse cursor is completely hidden to provide a pure, uninterrupted black screen.
* **Accident-Proof:** Clicking on the screen won't close it, preventing accidental exits if you bump your mouse.
* **Easy Exit:** Simply press the `ESC` key to close the black screen and return to your normal browser.
* **Ultra Lightweight:** Built with Manifest V3. It uses absolutely zero background resources when not active and requires no intrusive permissions.
* **Cross-Browser Compatibility:** Works flawlessly on Google Chrome, Mozilla Firefox, Microsoft Edge, Brave, and other Chromium-based browsers.

## 🎯 Perfect For

* Resting your eyes during long late-night working sessions.
* Keeping your PC awake while making the screen completely dark.
* Hiding distractions when you need to focus on background audio, music, or podcasts.
* OLED screen users looking to save battery and prevent screen burn-in.

## 🚀 How to Install (Manual Installation)

Since this extension is not yet published on the web stores, you can easily install it manually in just a few steps:

### For Google Chrome / Microsoft Edge / Brave (Chromium-based):

1. Download or clone this repository to your computer (`Code` > `Download ZIP`).
2. Extract the downloaded ZIP file to a folder.
3. Open your browser and navigate to the extensions page:
   * Chrome: `chrome://extensions/`
   * Edge: `edge://extensions/`
   * Brave: `brave://extensions/`
4. Enable **Developer mode** (usually a toggle in the top right corner of the page).
5. Click on the **Load unpacked** button that appears.
6. Select the folder where you extracted the extension files.

### For Mozilla Firefox:

1. Download or clone this repository to your computer.
2. Extract the downloaded ZIP file.
3. Open Firefox and navigate to the debugging page by typing `about:debugging#/runtime/this-firefox` in the address bar.
4. Click on the **Load Temporary Add-on...** button.
5. Select the `manifest.json` file inside the downloaded/extracted folder.

## 💡 How to Use

1. Once installed, pin the ScreenOff icon (the red power button) to your browser's toolbar for easy access.
2. Click the extension icon whenever you want to black out your screen.
3. Enjoy the darkness!

## ❌ How to Exit

To exit the black screen and return to your browsing session, simply press the **`ESC` (Escape)** key on your keyboard. 
*(Note: Mouse clicks are intentionally disabled to prevent accidental closures).*
